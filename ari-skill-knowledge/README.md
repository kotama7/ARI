# ARI Knowledge query Provider

This default-off MCP package exposes search, description, active-lock reads,
and non-authoritative next-epoch requests for **non-executable Knowledge
Skills**. It has no catalog registration, promotion, revocation, lock rewrite,
Provider invocation, credential, or Harness-selection tool.

The legacy package prefix `ari-skill-` identifies an MCP Capability Provider;
it does not make this package's catalog entries executable Skills.
