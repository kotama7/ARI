## 運用

- 各 gate review で当該 gate を blocking とする行の status を確認し、open のままの場合は gate を通過させない（P0 は「解消または blocking issue 化」が G0 exit 条件、plan 10 Wave 0）。
- risk の close には、是正 commit/PR と negative test（plan 09 §Testing）への link を記録する。
- 新規 risk は検証事実（file:line）を必ず添えて追記する。推測のみの行は追加しない。
