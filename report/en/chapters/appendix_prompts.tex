\section{Runtime LLM Prompts}\label{sec:prompts}

This appendix lists the LLM prompts that ARI uses at runtime, reproduced
verbatim from \texttt{ari-core/ari/prompts/} at v0.9.0. Each listing is
byte-for-byte identical to the source on disk. Because the exact bytes are
what reach the model, the prompts are reproduced as-is in every language
version of this report and are not translated.

The final four groups --- proposal generation, adversarial review,
governance, and prompt evolution --- were introduced after v0.9.0 by an
opt-in constitutional-governance execution mode (\texttt{ari\_rqgm});
the default pipeline never loads them. They are reproduced in the same
verbatim form. Under that mode the templates shown here are committed
seeds: prompt variants evolved at run time are stored inside the run's
checkpoint and never replace these files.
